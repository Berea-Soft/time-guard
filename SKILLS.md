# SKILLS

This document lists agent skills that are commonly used when working on this repository, with short descriptions and guidance for adding new skills.

## Known skills
- **caveman** — Ultra-compressed communication modes (lite, full, ultra).
- **caveman-commit** — Conventional Commit message generator.
- **caveman-compress** — Compress memory files into caveman format.
- **caveman-review** — One-line, ultra-compact code review comments.
- **caveman-help** — Quick-reference card for all caveman modes and skills.
- **find-skills** — Helps discover and install new agent skills.
- **skill-creator** — Guide for creating and updating effective skills.
- **project-setup-info-local** — Project scaffolding and initialization guidance.
- **agent-customization** — Rules and helpers for agent prompt files and customization.
- **typescript-upgrade** — Automated TypeScript/Node dependency upgrade workflow.

## Adding a skill
1. Create a `SKILL.md` under `.agents/skills/<skill-name>/` with a description, triggers, and usage examples.
2. Add a one-line entry here summarizing the new skill.
